# LUNO PIENO

Desktop-first homepage concept for the Swiss unisex clothing brand LUNO PIENO.

The design combines Swiss restraint with Mediterranean warmth and includes intentional media placeholders for campaign photography, product images, process footage, editorial stories, and community portraits.

## Local development

Requires Node.js `>=22.13.0` and pnpm.

```bash
pnpm install
pnpm dev
pnpm build
```

## Current homepage sections

- editorial campaign hero
- brand manifesto
- featured essentials
- Swiss and Portuguese craft story
- travel and lifestyle journal
- unisex community portraits
- newsletter and customer-care footer

The current version is a visual prototype. Commerce links, Shopify products, checkout, search, account, and newsletter submission are intentionally not connected yet.
